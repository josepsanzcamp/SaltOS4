PHPass (Legacy Compatibility)

This directory contains the original PHPass library
(Portable PHP password hashing framework)
by Solar Designer.

Source:
https://www.openwall.com/phpass/
https://github.com/openwall/phpass

Purpose:
This library is included only for compatibility with
legacy SaltOS 3.x password hashes.

It is NOT used for new password generation.
New versions of SaltOS use PHP native functions
(password_hash / password_verify).
